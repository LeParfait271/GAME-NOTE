# Pack visuel Game Note

Ce dossier regroupe les propositions d’identité visuelle générées pour le site.
Les fichiers sont séparés par usage afin de faciliter le choix avant intégration.

## Direction

- ambiance : archive noire, carnet de route, encre éditoriale, tension manga originale ;
- palette : bleu nuit / noir, ivoire papier, corail de repère, olive discret ;
- motif récurrent : route, boussole, carnet, jalons et marges de carte ;
- aucun visuel ne reprend un personnage, un logo ou une typographie d’une licence existante.

## Dossiers

- `logo/` : wordmarks et symboles de marque ;
- `icons/` : icône PWA / favicon candidate ;
- `banners/` : hero et bandeaux de sections ;
- `backgrounds/` : textures papier sombre et claire ;
- `cards/` : illustrations de fonctionnalités ;
- `social/` : aperçus Open Graph et couverture verticale.

Les fichiers sont des candidats. Rien n’est branché dans l’interface pour le moment.
