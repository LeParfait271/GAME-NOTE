FALLOUT TACTICS: BROTHERHOOD OF STEEL

GARDE-FOUS ET MISSABLES

- Le jeu permet parfois de choisir entre deux missions. Le choix change
  seulement l'ordre : termine les deux avant le bunker suivant et coche-les
  dans cette fiche.
- Fais une sauvegarde au bunker avant chaque depart, puis une sauvegarde
  rapide a chaque objectif sensible. Le mode Tough Guy interdit la sauvegarde
  pendant la mission : utilise le mode Normal pour une route 100 % confortable.
- Une mission se termine uniquement a l'extraction. Avant de quitter la zone,
  ouvre l'onglet Objectives et verifie Main et Optional, puis fouille les
  coffres, cadavres, maisons, bunkers et vehicules.
- Les civils, prisonniers, ghoules, tribaux, reavers et recrues peuvent compter
  dans les objectifs optionnels. Ne lance pas une rafale ou une grenade pres
  d'une cible a sauver.
- Les versions et traductions alternent Peoria/Preoria, Cold Water/Coldwater
  et Osceolla/Osceola. Les noms de cette fiche suivent les noms Steam les plus
  courants ; le briefing du jeu reste la reference si l'interface differe.

PREPARATION DU SQUAD

- Cree un personnage polyvalent avec une competence de combat principale,
  Medecine, Reparation, Traps et Sciences reparties dans l'equipe.
- Garde un eclaireur en Sneak, un medecin, un specialiste des pieges et un
  porteur d'arme lourde. La composition peut changer, mais ces quatre roles
  evitent la plupart des blocages.
- Passe en tour par tour pour les mines, tourelles, otages, portes et combats
  de boss. Le temps reel continu sert surtout a traverser une zone deja sure.
- Apporte kits de soin, trousses de medecin, outils, munitions, explosifs et
  antidotes. Vends le surplus au bunker et garde une arme de rechange par type.

ORDRE CHRONOLOGIQUE DES MISSIONS

TUTORIEL - BASIC, AMBUSH, STEALTH, SNIPER

- Termine les quatre entrainements, teste le tour par tour, le mode continu,
  les angles de tir, la discretion et la sauvegarde d'equipement.
- Les tutoriels ne comptent pas dans les 21 missions, mais ils debloquent les
  bons reflexes pour les pieges et les recrues. [ ] quatre tutoriels.

01 - BRAHMIN WOOD / BUNKER ALPHA

- Suis le briefing, infiltre le camp et elimine le chef Raider. Explore les
  enclos, les huttes et les caisses avant de rejoindre la sortie.
- Recupere les armes, soins, munitions et le butin du chef. Les objets de
  mission doivent etre places sur le personnage principal ou dans un inventaire
  de squad avant l'extraction.
- Au bunker, vends les doublons, equipe les nouvelles recrues et prends les
  livres ou armes proposes par le quartier-maitre.
- [ ] Chef Raider ; [ ] caisses ; [ ] cadavres ; [ ] extraction ; [ ] bunker.

02 - FREEPORT / BUNKER ALPHA

- Explore les quais et les maisons en restant a distance des alarmes. Repere
  les interrupteurs, les cages et la sortie avant de lancer l'assaut.
- Neutralise les chefs Raider, libere les cibles prisonnieres et fouille les
  pieces de service. Une alarme peut attirer plusieurs groupes : utilise
  l'eclaireur pour ouvrir la route et le squad pour tenir l'intersection.
- Termine par la zone du chef, recupere la cle et valide toutes les options
  avant l'extraction.
- [ ] Chefs ; [ ] prisonnier ; [ ] alarme ; [ ] entrepots ; [ ] sortie.

03 - ROCK FALLS / BUNKER ALPHA

- Objectif principal : eliminer Daisy-May Gomer, Jesse Gomer, Bo Duffy et Luke
  Daniels, puis recuperer le dispositif.
- Objectifs optionnels : liberer le scientifique Diesoon et le tribal Nanuk.
  Traite-les avant de tuer le dernier chef et parle-leur plusieurs fois.
- Fouille les laboratoires, les casiers et les tables de travail. Recupere les
  livres et objets scientifiques avant de quitter la zone.
- [ ] 4 chefs ; [ ] dispositif ; [ ] Diesoon ; [ ] Nanuk ; [ ] caisses.

04 - MACOMB / BUNKER BETA

- Rencontre le survivant, active les interrupteurs des portes et escorte le
  vehicule jusqu'a la sortie. Le Hummer devient un outil de stockage et de
  protection : ne le laisse pas sous le feu des lance-roquettes.
- Fais l'objectif optionnel de la bibliotheque : retrouve les lunettes dans un
  coffre et rends-les a Phillip Wilson pour obtenir son livre.
- Fouille les toits et les balcons avant l'extraction, surtout les positions
  de snipers. Termine l'escorte avant de vendre le vehicule ou son contenu.
- [ ] Survivant ; [ ] interrupteurs ; [ ] lunettes ; [ ] Hummer ; [ ] sortie.

05 - PEORIA / BUNKER BETA

- Recupere les trois batteries a fusion dans le bunker. La route passe par les
  cartes, les interrupteurs et plusieurs tourelles : un personnage avec Traps
  et un autre avec Sciences rendent la zone bien plus sure.
- Objectifs optionnels : ne blesser aucun tribal et obtenir la quatrieme
  batterie. Passe les defenses interne/externe avec des sauvegardes ; ne laisse
  pas l'interrupteur actif assez longtemps pour toucher le village.
- Prends Rad-X et antidotes avant la salle finale. Remets les defenses dans un
  etat qui laisse le chemin de retour accessible, puis parle a l'ancien avant
  l'extraction.
- [ ] 3 batteries ; [ ] quatrieme batterie ; [ ] tribaux sauves ; [ ]
  tourelles ; [ ] coffres ; [ ] retour.

06 - QUINCY / BUNKER BETA

- Objectifs principaux : sauver Hillary Eastwood, la maire, puis Evita, sa
  fille. Active l'alarme utile sans detruire la sirene qui protege les otages.
- Objectifs optionnels : sauver tous les otages, preserver les generateurs,
  sauver Felix Stiles, aider les ghoules et retrouver Gorgi.
- Travaille par batiment : utilise les echelles, desactive les lumieres,
  desarme les pieges et garde un medic avec des trousses. Evite les rafales
  pres des prostituees, civils et otages.
- Retourne parler a la maire plusieurs fois apres les sauvetages. C'est aussi
  le moment de controler les nouvelles recrues accessibles au bunker.
- [ ] Hillary ; [ ] Evita ; [ ] otages ; [ ] generateurs ; [ ] Felix ;
  [ ] ghoules ; [ ] Gorgi ; [ ] recompenses.

07 - MARDIN / BUNKER BETA

- Infiltre la taniere des Beastlords, explore la surface et les galeries, puis
  elimine leur chef. L'objectif secondaire demande d'identifier la source du
  controle des deathclaws.
- Garde la matriarche en vie si tu veux ouvrir la branche de recrues et les
  informations supplementaires. Fais une sauvegarde avant la derniere salle.
- Le labyrinthe contient des armes, des munitions et des recrues potentielles.
  Ne quitte pas des que le chef est neutralise : verifie le journal et les
  corps, puis reviens au bunker.
- [ ] Chef Beastlord ; [ ] source identifiee ; [ ] matriarche ; [ ] recrues ;
  [ ] objets ; [ ] extraction.

BONUS - SPRINGFIELD / BUNKER BETA

- Cette mission depend du pack bonus installe avec certaines editions. Elle
  n'est pas necessaire pour la campagne de base, mais elle doit etre cochee
  pour un 100 % du contenu disponible dans ton installation.
- Fais-la avant de quitter Bunker Beta, puis controle le pool de recrues et le
  quartier-maitre. [ ] Springfield terminee si presente.

08 - ST. LOUIS / BUNKER GAMMA

- Localise les soldats survivants et evacue les trois escouades avec l'APC.
  Le vehicule ne doit pas etre detruit et peut transporter le groupe a travers
  les tranchees.
- Soigne les soldats avec Medecine ou trousses, puis conduis l'APC a l'exit.
  Les mines doivent etre detectees et desarmees par l'eclaireur.
- Aide Burke si tu veux l'objectif optionnel et fouille les bunkers pour les
  fusils de precision, livres et trousses. Ne t'enlise pas dans la base de
  mutants si le journal affiche deja tous les objectifs.
- [ ] 3 escouades ; [ ] soldats soignes ; [ ] APC ; [ ] Burke ; [ ] mines ;
  [ ] objets ; [ ] extraction.

09 - JEFFERSON / BUNKER GAMMA

- Detruis les quatre generateurs. Nettoie d'abord le complexe central et les
  toits, puis avance generateur par generateur.
- Les mines et pieges autour des batiments sont plus dangereux que les
  premiers ennemis. Passe en tour par tour, utilise Traps et garde une sortie
  libre pour les personnages blesses.
- Le scouter peut servir de stockage ; il n'est pas un substitut a une equipe
  capable d'entrer dans les maisons. [ ] 4 generateurs ; [ ] mines ; [ ]
  complex central ; [ ] scouter ; [ ] extraction.

10 - KANSAS CITY / BUNKER GAMMA

- Protege Bishop et tiens les portes pendant les vagues de mutants. Sauvegarde
  juste apres le briefing afin de tester la repartition du squad.
- Elimine les chefs et les vagues restantes avant de reparler a Bishop. Les
  armes lourdes et les positions de couverture sont prioritaires ; fouille les
  ghoules et les mutantes apres chaque vague.
- Recupere Rad-X, armes et munitions dans les maisons, puis valide la sortie
  sur le bord de la carte. [ ] Bishop ; [ ] vagues ; [ ] chefs ; [ ] butin.

11 - OSCEOLLA / BUNKER GAMMA

- Elimine Gammorin dans la base des super-mutants. Choisis une entree qui te
  laisse une ligne de retraite ; le tunnel radioactif est le chemin le moins
  confortable.
- Explore la base et valide l'objectif optionnel lie a General Barnaky avant de
  tuer le dernier chef. Les armes lourdes, les mines et les pieges des portes
  demandent de la patience.
- Controle le pool de recrues apres la mission, notamment les mutants et les
  personnages qui deviennent disponibles. [ ] Gammorin ; [ ] Barnaky ; [ ]
  armurerie ; [ ] recrues ; [ ] extraction.

12 - JUNCTION CITY / BUNKER DELTA

- Fais le tour de la ville et repere les positions en hauteur, les commerces,
  les barricades et les maisons. Suis le briefing pour les objectifs principaux
  sans laisser les caches optionnelles derriere toi.
- Neutralise les forces ennemies par petits groupes, desamorce les mines et
  protege les survivants quand le journal les mentionne.
- Recupere les armes et livres de competence, puis retourne au point d'extraction
  seulement apres le controle des objectifs.
- [ ] Objectifs du briefing ; [ ] survivants ; [ ] mines ; [ ] commerces ;
  [ ] livres ; [ ] caisses.

13 - GREAT BEND / BUNKER DELTA

- Explore la zone industrielle et identifie les poches de robots. Les angles
  de tir et la munition adaptee comptent plus que la vitesse.
- Protege les allies et ouvre les portes techniques avec Reparation ou Sciences.
  Ne depense pas tous les explosifs sur les premiers robots : la fin de mission
  demande souvent un gros vehicule ou une arme lourde.
- Fouille les hangars et les ateliers avant l'extraction. [ ] zone industrielle ;
  [ ] allies ; [ ] portes ; [ ] robots ; [ ] ateliers.

14 - COLD WATER / BUNKER DELTA

- Traite la route d'eau, les campements et les positions ennemies dans l'ordre
  du briefing. Les ennemis peuvent revenir derriere le groupe : garde un
  eclaireur en couverture.
- Valide les objectifs optionnels de civils et de ressources avant la sortie.
  Les caisses de soins, munitions et outils sont prioritaires a la fouille.
- Controle le nouveau materiel au bunker. [ ] objectifs principaux ; [ ] civils ;
  [ ] fournitures ; [ ] sorties ; [ ] recrues disponibles.

15 - NEWTON / BUNKER DELTA

- Sauve les quatre anciens Reaver et recupere le prototype d'arme. Le tank est
  le meilleur moyen de traverser les robots : protege-le et ne le bloque pas
  entre deux batiments.
- Fais une sauvegarde avant chaque extraction d'ancien. Les maisons, coffres
  et recoins contiennent les objets qui permettent de maintenir le tank.
- Recupere le prototype dans le coffre securise, puis verifie que les quatre
  personnes sont comptees avant de quitter. [ ] 4 anciens ; [ ] prototype ;
  [ ] tank ; [ ] fournitures ; [ ] recrues Reaver.

16 - CANYON CITY / BUNKER EPSILON

- Detruis le centre de reparation robotique et neutralise ses consoles. Les
  robots lourds exigent une arme perce-armure, explosives ou EMP.
- Explore les ateliers, les hangars et les zones de maintenance. Recupere le
  robot HR-1205 si l'objectif et la condition de recrutement apparaissent.
- Ne detruis pas un terminal avant de l'avoir lu et sauvegarde avant la salle
  de production. [ ] centre detruit ; [ ] consoles ; [ ] HR-1205 ; [ ] butin.

17 - BUENA VISTA / BUNKER EPSILON

- Sabote la chaine de production et traite les sources d'energie dans l'ordre
  du briefing. Les behemoths et les lance-roquettes doivent etre marques par
  l'eclaireur avant le combat.
- Fouille les laboratoires et les salles de securite. Garde les grenades EMP,
  les explosifs et les armes lourdes pour les groupes blindes.
- Valide les objectifs optionnels de prisonniers ou de terminaux si le journal
  les affiche. [ ] production ; [ ] energie ; [ ] robots lourds ; [ ] cellules ;
  [ ] extraction.

18 - SCOTT CITY / BUNKER EPSILON

- Retrouve Bartholomew Kerr et determine s'il doit etre sauve ou neutralise.
  Retrouve egalement la trace de General Barnaky sans declencher la derniere
  salle avant d'avoir fini les options.
- Detruis les quatre tours de brouillage pour restaurer la mini-carte et sauve
  les prisonniers. Les behemoths et hover bots demandent une progression lente.
- Utilise un personnage de Reparation ou de Sciences sur les portes et les
  consoles ; garde le groupe en formation pour eviter les tirs de roquettes.
- [ ] Kerr ; [ ] Barnaky ; [ ] 4 tours ; [ ] prisonniers ; [ ] behemoths ;
  [ ] mini-carte ; [ ] extraction.

19 - MONT CHEYENNE / BUNKER EPSILON

- Prepare la charge de fin, les explosifs, les soins et les armes lourdes.
  Nettoie la pente, les positions de garde et les portes avant d'approcher le
  point de pose.
- Pose la charge au bon endroit, puis assure l'evacuation. Le groupe doit etre
  complet et l'inventaire des objets de quete verifie avant la transition.
- La mission ouvre la route du Vault 0. [ ] defenses ; [ ] charge ; [ ]
  equipement final ; [ ] extraction.

20 - VAULT 0

- Reunis la puissance auxiliaire, ouvre les ascenseurs et explore les niveaux
  dans l'ordre des terminaux. Les robots resistants rendent les EMP et les
  armes lourdes indispensables.
- Fais des sauvegardes au bunker avant l'entree, au retour de l'alimentation et
  avant le dernier ascenseur. Verifie les coffres, medikits et armes uniques.
- Traite la rencontre de fin de niveau avec la competence ou le combat adapte
  a ton equipe ; le guide ne donne aucun resultat narratif.
- [ ] alimentation ; [ ] ascenseurs ; [ ] niveaux ; [ ] terminaux ; [ ]
  armureries ; [ ] dernier checkpoint.

21 - CALCULATOR'S LAIR

- Fais la sauvegarde finale au Vault 0. Equipe les meilleures armes, distribue
  les munitions, remplis les soins et garde une place libre pour les objets de
  mission.
- Traverse les dernieres defenses, lis les terminaux et neutralise les
  objectifs gardes par le briefing. Utilise les couvertures et laisse l'eclaireur
  detecter les pieges avant chaque porte.
- La fin propose des choix. Le guide reste sans spoiler : conserve le slot
  avant le choix, termine une issue, recharge puis compare l'autre si tu veux
  verifier toutes les variantes sans perdre ta route principale.
- [ ] dernieres defenses ; [ ] terminaux ; [ ] choix sauvegardes ; [ ] campagne.
